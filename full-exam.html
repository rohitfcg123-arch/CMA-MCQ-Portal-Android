How the random paper is prepared

Random mode does not create new questions. It selects from the existing MCQ bank and existing subjective/PYQ pool for the selected subject. Subjective selection is spread across the available previous attempts when possible, so repeated attempts can produce a different paper. The exact ICMAI paper pattern is not being claimed; this is a CMA Zone full-length practice exam.
