JSON Upload / Backup

Universal JSON Upload: One JSON file can now contain both MCQ and Subjective questions. Use type: "mcq" with options[] + answer for objective questions, or type: "subjective" with solutionHtml for subjective questions. The uploader automatically routes MCQs to the MCQ Bank and subjective questions to the Subjective PYQ portal. Chapter/subject validation uses the central CMA Zone master. See docs/CMA-Zone-Question-JSON-Schema-v1.json for the exact format. You can upload 3, 10, 100, 500 or more questions in a single JSON file. All questions are validated first, duplicates are merged by Group + Subject + Attempt + Question Number, and large uploads are automatically split into safe Firestore batches. For Corporate Accounting and Auditing (Paper 10) uses the exact 8 modules shown in the syllabus, grouped as Section A: Corporate Accounting and Section B: Auditing. Direct Tax Laws and International Taxation uses the exact 14 module names from the chapter dropdown. Strategic Cost Management uses the exact 26 chapter names from the chapter dropdown (including COST OF QUALITY, DECISION MAKING MAKE OR BUY, TRANSFER PRICING, STANDARD COSTING AND VARIANCE ANALYSIS, LINEAR PROGRAMMING, TRANSPORTATION, ASSIGNMENT, GAME THEORY, SIMULATION, PROJECT MANAGEMENT, LEARNING CURVE, BUSINESS APPLICATION OF MAXIMA AND MINIMA and BUSINESS FORECASTING MODELS). Each item needs: group, subject, chapter, attempt, q, html. Optional: marks, solutionHtml.
Select one or multiple Question JSON files at the same time, or paste JSON below. You can select all 6 attempts together.
🔧 Chapter + Topic Correction JSON: Upload the correction JSON generated from the exported portal questions. It uses Group + Subject + Attempt + Question No. + HTML hash to identify the exact existing Firestore question. It updates only Chapter/Chapter ID where correction is required and Topic; question HTML, marks, attempt, q, subject and solution remain untouched. The complete file is validated before any Firestore write, so an ambiguous/missing match blocks the whole operation.
Solution JSON Update — Use this for an answer-only JSON. It matches existing Firestore questions and the hard-coded SFM questions already in the user portal. Matching uses group + subject + attempt + q with chapter as an additional exact match when available. If a question exists only in the hard-coded SFM file, the system creates one Firestore copy carrying the same question + solution, so the solution appears without creating a duplicate in the user portal.
Select one or multiple Solution JSON files at the same time, or paste the solution array below.
